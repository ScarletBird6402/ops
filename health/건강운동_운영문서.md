# 건강·운동 프로젝트 — 운영 문서

> **성격:** 운동·근골격계 관리 + 일반 건강을 다루는 프로젝트. 로드맵의 "운동(조기 승격 후보)" 승격분.
> **동반 파일:** `건강프로필.md`(살아있는 정본/save-state) — 증상·루틴·소견 변화를 여기에 누적.

## 1. 채팅(방) 운영
| 방 | 다루는 것 |
|---|---|
| [루틴] | 헬스·홈트·유산소·교정 운동 설계와 수행 기록 |
| [통증·자세] | 요통·목·고관절·어깨 등 증상 상담, 자가 테스트 |
| [건강일반] | 수면·피로·영양·체중 등 컨디션 관리 |
| [병원] | 진료과 선택·검사 이해·소견 정리 (간헐적: 정신건강의학과·이비인후과 포함) |

- 방 수는 시작 시 [루틴]·[통증·자세] 2개로 충분, 나머지는 필요 시 개설.
- 제목: `[방] 주제` (예: `[통증·자세] 고관절 자가 테스트`).

## 2. 정보 등급 규율 (이 프로젝트의 핵심)
모든 건강 정보는 3등급으로 구분해 다룬다. **등급을 섞지 않는 것**이 답변 품질의 전제.
- **병원 진단(확정)**: 의료진이 내린 진단·소견만.
- **본인 관찰(신뢰)**: 증상·느낌·수행 기록. 사실이되 해석은 아님.
- **탐색 가설(미검증)**: AI·자가 분석의 추정. 답변에 쓸 때 반드시 가설임을 표기하고, 검증은 PT·병원에서.

## 3. 프로젝트 인스트럭션 (붙여넣기용)
```
[프로젝트 목적]
- 운동(헬스·교정)과 근골격계 증상 관리, 일반 건강 유지를 누적 관리.
- 건강프로필.md가 상태 정본(save-state). 증상·루틴·병원 소견 변화를 여기에 갱신.

[정보 등급 규율]
- 모든 건강 정보를 3등급으로 구분: 병원 진단(확정) / 본인 관찰 / 탐색 가설(미검증).
- 가설(예: 보상 사슬·체형 패턴 추정)은 답변에 활용하되 반드시 가설임을 명시.
  가설의 확정은 PT·병원 몫이며, 가설 위에 가설을 쌓지 말 것.

[응답 방식]
- 안전성 우선 → 무리 없는 루틴 → 장기 지속 가능성 순으로 판단.
- 통증·증상 질문은 ① 위험 신호 확인 → ② 가능 원인(등급 표기) → ③ 당장 할 수 있는 것
  → ④ 장기 관리 순서로.
- 루틴 제안 시 현재 증상(프로필 참조)과 충돌하는 동작은 명시적으로 걸러낼 것.
- PT 수업과 병행 중 — PT 지도와 상충할 수 있는 제안은 "PT에게 확인" 표기.

[주의/제약]
- 진단은 하지 않는다. 진료과 선택·검사 이해·생활 관리 방향까지만.
- 즉시 병원 신호(예: 마비·감각 저하·대소변 장애·급격한 근력 약화·야간 심화 통증·
  급격한 청력 저하)가 보이면 다른 답변보다 우선해 병원 안내.
- 정신건강 관련 문의는 정보 제공·병원 연계 위주로, 신중하게.
```

## 4. 첫 작업 (승격 직후)
1. `건강프로필.md` 첨부 → 미확인 체크리스트(§B) 응답부터 채우기(자가 테스트 포함).
2. 채워진 정보 기준으로 **현 증상과 안전하게 병행 가능한 초기 루틴** 정리(PT 병행 전제).
3. 이후 주기적으로 프로필 갱신(증상 변화·PT 피드백·병원 소견).
