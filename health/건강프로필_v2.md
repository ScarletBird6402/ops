## D. 주요 증상 [관찰]
1. **요통** — 위치: 골반 윗선(장골능 라인) 기준 아래쪽 경계를 따라 좌우로 띠처럼 분포.

   - 아래쪽 중앙: 오래 앉아 있으면 불편감
   - 불편감의 성질·시간 패턴(기상 직후/일어날 때 등): **미기록 — 추가 답변 예정** (§I)
2. **목** — 평소 무증상, 장시간 업무 시 뻐근.
3. **고관절(우측 중심 비대칭)** — 우측 불편감·간헐적 찝힘. 앉을 때 좌우 불균형감. 스쿼트 시 좌우 힘 위치 다름. 다리 들기/쪼그려 앉기 시 우측 골반 돌출부 전하방에 힘 집중. 거울 스쿼트 시 우측 골반이 앞으로 처져 보일 때 있음. 대퇴골두가 뒤로 빠지는 느낌(불확실). 우측 사타구니가 좌측보다 타이트. → 상세 계측은 E 참조
4. **어깨(우측 불안정)** — 우측 견갑 불편감. 가슴 뒤로 젖힐 때 좌측은 견갑만 움직이는데 우측은 상완골두가 함께 움직이는 느낌. 우측 어깨 움직임 시 소리(벽 만세·등 뒤 깍지에서는 미발생). PT 지적: 벤치프레스 시 우측이 아래로 처짐. → 상세 계측은 E 참조

**유지 (v1에서 계승)**
- 연쇄 가설: 골반-흉추-견갑대 정렬 → 고관절 비대칭 → 허리 과부하 → 목/어깨 보상 (1차=고관절/골반)

- 우선순위: 고관절/골반 > 허리 > 견갑/어깨 > 목

**갱신·구체화 (v2 테스트 기반)**
- **고관절**: "전체 경직"보다 **"깊은 굴곡 방향에서만 앞쪽이 걸리는 국소적 제한"**에 가까움. 설명 후보 2갈래 (배타적 아님):
  - 후보 1 — 앞쪽 연부조직 긴장 (PT 소견과 같은 방향)
  - 후보 2 — 깊은 굴곡 시 대퇴골두 후방 활주 부족 (본인의 "대퇴골두 뒤로 빠지는 느낌" [관찰]과 접점)
  - 실전 분기점: 스트레칭 2~3주 후에도 찝힘 각도 불변 시 다른 접근 필요한지 [PT에게 확인]
- **어깨(우측)**: 범위 부족보다 **"움직임의 질/제어" 문제**에 무게. 근거 정황: 범위는 됨(벽 먼저 닿음) + 항상 뒤쪽 걸림, 상완골두 동반 이동 서술, 하중 시 처짐, 방향 특이적(내회전 계열) 제한. Pattern C와 부합. → 스트레칭만으로는 절반, 이후 견갑 제어 운동 필요 가능성 [PT에게 확인]
