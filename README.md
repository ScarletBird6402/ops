# ops — 운영 레포 (영구 비공개)

학습자료 파이프라인의 **운영 층**. 마스터플랜·브리프·배정/세션 로그·킷 백업이 여기에만 들어간다.

> ⚠ **이 레포는 영구 비공개다. 공개 전환 금지.**
> 공개 산출물 레포(swe-notes · ai-engineering-notes · algorithm-notes)에 운영 문서가 발견되면
> 게시-검증 에이전트가 FAIL 처리한다. 티어를 섞지 말 것.

## 폴더 구조

| 폴더 | 들어가는 것 |
|---|---|
| `plans/` | 마스터플랜(본부판) — 커리큘럼 배정·코드 체계 운영본 |
| `briefs/` | 항목별 생성 브리프(코드·주제·키워드) |
| `logs/` | 세션 로그 — 생성·검증·커밋 기록 |
| `kit/` | Claude Code 킷 백업 (`CLAUDE.md`, `agents/`) |

## 킷 백업의 역할

작업 루트 `claude-work/`의 `CLAUDE.md`와 `.claude/agents/`는 **어느 레포에도 속하지 않는다**
(커밋될 경로 자체가 없게 만든 구조적 차단). 대신 이 레포 `kit/`에 사본을 두어,
다른 PC 셋업 시 여기서 복원한다.

원본을 수정했다면 `kit/`도 함께 갱신할 것 — 동기화는 수동이다.

### 복원 절차 (새 PC)
1. 작업 루트 폴더 생성 후 그 안에 각 레포 클론
2. `kit/CLAUDE.md` → 작업 루트에 복사
3. `kit/agents/*.md` → 작업 루트 `.claude/agents/`에 복사

## 세션 로그 규칙

파일명 `YYYY-MM-DD 주제.md`. 한 사이클(생성 → 검증 → 커밋)이 끝나면 선택적으로 남긴다.
사용량(`/usage`) 관찰치를 함께 적어두면 플랜 판단 데이터가 된다.
