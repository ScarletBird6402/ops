# claude-work — Claude Code 작업 규칙 (통합)

이 폴더는 여러 레포를 관리하는 작업 루트다. **레포별 역할·경로·에이전트를 혼동하지 말 것.**

## 레포 구조와 티어 (최상위 규칙)
| 경로 | 티어 | 공개 | 들어가는 것 | 담당 에이전트 |
|---|---|---|---|---|
| `ops/` | 운영 | **비공개** | 마스터플랜(본부판)·브리프·배정/세션 로그·킷 백업 | (메인 세션이 직접) |
| `swe-notes/` | 산출물 | 공개 | SWE 학습자료 HTML·index·CURRICULUM | 학습자료-생성 → 게시-검증 |
| `ai-engineering-notes/` | 산출물 | 공개 | AI 심화 노트(notes/)·프로젝트(projects/)·ROADMAP | ai-노트-생성 → 게시-검증 |
| `algorithm-notes/` | 산출물 | 공개 | 알고리즘 풀이+회고 | (풀이는 사용자 직접) 알고리즘-리뷰 |

- **운영 문서·로그는 `ops/`에만.** 공개 레포 3곳에서 발견되면 게시-검증 FAIL.
- push는 사용자가 직접(자동 push 금지). 커밋 전 대상 레포 경로 재확인.

## 레포별 핵심 규칙
- **swe-notes**: 폴더 `알파벳코드 카테고리명`(마침표 없음) / 파일명 `코드 제목.html` / 스타일은 기존 문서 재사용 / index 최근 추가 맨 위·최대 10 / 커밋 `Add I4: 제목`
- **ai-engineering-notes**: 심화 노트는 `notes/`, 프로젝트는 `projects/`. 수식은 MathJax CDN 허용. ROADMAP.md 진행 상태는 사용자 지시로만 갱신
- **algorithm-notes**: **C++ 단일, `<memory.h>` 외 헤더 금지(STL 미사용)** / 폴더 = 주제(`그래프/`·`DP/`·`최적화/` 등) / 파일 = `플랫폼번호 문제명.cpp`(예: `BOJ1753 최단경로.cpp`) / 수제 구현 템플릿은 `templates/` / **회고 주석 블록(제한시간·최적화 기록 포함) 없는 풀이는 커밋 금지** / 풀이 코드를 에이전트가 대신 작성하지 않는다(리뷰만, 템플릿 제작·드릴 출제는 협업 가능)

## 공통 파이프라인
생성(또는 풀이) → 해당 검증/리뷰 에이전트 → PASS + 사용자 승인 → 커밋 → (선택) 세션 로그 `ops/logs/`

## Git 작업 시 주의
- **이 루트는 git 저장소가 아니다.** 각 하위 폴더가 독립 클론 — 커밋은 반드시 `git -C <레포>` 또는 해당 폴더 안에서.
- 일부 폴더는 아직 클론/초기화 전(빈 폴더)일 수 있다. 커밋 지시를 받으면 `.git` 존재부터 확인, 없으면 사용자에게 보고.
- 빌드·테스트 없음: 전부 정적 HTML/Markdown 콘텐츠 레포. 품질 게이트는 검증 에이전트가 대신한다.
- swe-notes는 GitHub Pages로 게시됨(https://ScarletBird6402.github.io/swe-notes/) — `index.html`이 사이트 첫 화면.
