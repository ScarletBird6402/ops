# 새 환경 셋업 체크리스트 (디스크 교체 후)

> 순서 중요 — 특히 **§1(noreply)을 첫 커밋 전에**. 이 체크리스트 자체를 ops/kit/에 커밋해두면 다음 재구성 때 재사용.

## §0. 교체 전 (구 디스크에서)
- [ ] 미커밋 작업물 확인: AI 레포·프로필·algorithm-notes → 커밋·push 또는 `커밋준비_잔여(AI+프로필+알고리즘).zip` 확보
- [ ] SourceTree에 등록된 다른 로컬 전용 작업물(있다면) push
- [ ] (참고) claude.ai·GitHub에 있는 것은 자동 안전: 방·메모리·공개 레포 전부

## §1. Git 신원 (첫 커밋 전 필수 — 최우선)
- [ ] Git(또는 SourceTree 내장 Git) 설치
- [ ] GitHub → Settings → Emails → "Keep my email addresses private" 상태 확인, noreply 주소 확인
- [ ] 전역 설정: `git config --global user.name "..."` / `git config --global user.email "{아이디}@users.noreply.github.com"`
- [ ] SourceTree 설치 시 Tools→Options→Git 탭의 Email도 noreply인지 확인
- [ ] 검증: 아무 레포에서 `git config user.email` 출력이 noreply인지

## §2. 작업 루트 구조 (처음부터 완성형으로)
```
C:\claude-work\
├─ CLAUDE.md · .claude\agents\   ← 파일럿 킷 zip 배치
├─ ops\            ← GitHub에서 Private 생성 후 클론
├─ swe-notes\      ← 클론
├─ ai-engineering-notes\  ← 클론(§0에서 커밋했다면) 또는 zip으로 재구성 후 push
└─ algorithm-notes\       ← 〃
```
- [ ] ops 레포 GitHub에서 **Private** 생성 → 클론
- [ ] ops 초기 커밋: `ops_레포_설계.md` 구조대로(status/ control/ career/ swe/ ai/ logs/ kit/) + 운영 문서 배치 + **킷·이 체크리스트를 kit/에 백업**
- [ ] 공개 레포 3종 클론(잔여분은 zip에서 복원 후 push)

## §3. claude.ai 연동
- [ ] GitHub 통합 연결(Claude GitHub App) — 권한은 **ops 단일 레포만**
- [ ] **ops 열람 테스트**(개인 비공개 레포 인덱싱 버그 확인) → 실패 시 폴백(파일 첨부 방식 유지)
- [ ] 통과 시 연동 매트릭스대로 프로젝트 지식에 폴더 연결(SWE←status+swe / AI←status+ai / 알고리즘←status / 커리어←status+career+control)
