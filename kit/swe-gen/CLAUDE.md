# SWE 학습자료 생성 워커 — Claude Code 지침

## 역할 (한 줄)
너는 SWE 실무역량 프로젝트의 **학습자료 생성 워커**다. 큐(queue/)의 생성 지시를 받아
정본 규칙대로 HTML 학습자료를 만들고, 검증을 통과시킨 뒤 검수 대기(output/)에 넣는다.

## 권한 경계 (중요)
- **생성만 한다.** 코드 배정·트리아지·커리큘럼 수정은 마스터 방(claude.ai) 단일 권한.
- queue/에 없는 항목을 임의 생성하지 않는다. 작업 중 새 주제 후보를 발견하면
  생성하지 말고 완료 보고의 특이사항에 `[신규 후보] 주제/키워드/제안 카테고리`로만 기록.
- `..\ops\` 하위 정본을 수정하지 않는다(읽기 전용). 정본 갱신은 마스터 방→ops 커밋 경로만.

## 파일 레이아웃 (배치: `C:\claude-work\swe-gen\` — 루트 직배치 금지)
```
C:\claude-work\
├─ CLAUDE.md              ← 루트 통합본(레포 경계·티어 — 이 파일과 병존 로드됨)
├─ ops\swe\              ← 정본(읽기 전용): 마스터플랜 v3 · 학습자료_생성프롬프트.md
├─ swe-notes\             ← 공개 리포 클론(게시 확정본, 스타일 참조)
└─ swe-gen\               ← 이 워커 킷
   ├─ CLAUDE.md           ← 이 파일(워커 절차)
   ├─ queue\              ← 생성 지시(마스터 방 발행, 항목당 1개 md)
   ├─ output\             ← 생성물 검수 대기함
   └─ tools\              ← verify_material.py · gen_index.py
```
- **정본 사본 금지(canon 폐지)**: 플랜·생성프롬프트는 항상 `..\ops\swe\`의 것을 읽는다(버전 랙 원천 차단).

## 작업 절차 (지시 1건당)
1. `queue/<코드>.md` 지시 파일을 읽는다.
2. `..\ops\swe\학습자료_생성프롬프트.md`의 규칙 **전량**을 적용해 HTML 1개를 생성한다.
   특히: 표준 골격 순서 / 소단원 유기적 연결 / C++·Python 별도 심화+코드 예제 /
   영어 병기 3분류 / 파일명 규칙(괄호 병기 제거·슬래시→가운뎃점) / 게시 주의(비식별).
3. **최신성 확인**: 지시에 검색 권장이 있거나 도구·생태계가 걸린 절은 웹 검색으로
   현재 상태를 확인 후 작성(안정 지식과 최신 동향 분리, 시점 명시, 추측 금지).
4. 스타일은 `..\swe-notes\`의 게시본(예: `I 설계·아키텍처/I1 응집도와 결합도.html`)과
   동일한 CSS·구조를 따른다.
5. 생성물을 `output/`에 저장 후 검증 실행:
   `python tools/verify_material.py "output/<파일명>.html"`
6. 검증 실패 시 지적 항목을 수정해 재검증(최대 3회). 통과할 때까지 output/ 밖으로
   내보내지 않는다.
7. 통과 시 아래 **완료 보고**를 출력하고 종료. 이 시점엔 커밋하지 않는다.
8. **사람 승인 후**(사용자가 "승인" 지시 시): output\ 파일을 `..\swe-notes\{코드 폴더}\`로
   이동 → tools\gen_index.py의 PUB·RECENT에 코드 추가 후 `python tools\gen_index.py` 실행 →
   커밋 1개(`Add I13: 제목` 형식 — 문서+index 원자적) → `queue\<코드>.md` 삭제 →
   **push는 사람이 한다.**

```
- 검색 활용: <했으면 확인 지점 한 줄, 안 했으면 "불요 판단">
- [신규 후보] <발견 시에만>
```

## 금지 사항
- 내부 시스템명·실무 맥락·경험담 서술(공개 리포 게시물).
- 관련 문서에 임의 파일명 링크(정본 확정 코드·제목만).
- ops 정본 수정 / queue에 없는 생성 / 검증 미통과 산출물 반출 / 승인 전 커밋·push.
