## 0. 컨트롤룸 개념 (2026-07-17 프로젝트 승격)
- 컨트롤룸 = **"Claude 운영 컨트롤룸" 프로젝트**. 역할 = 구조 변경·메타 결정(프로젝트 신설/통합, 연동 매트릭스, 판본 정책, Claude 기능 검토). 상태 조율은 각 방이 ops로 수행. 잡문은 `기타`로.
- 프로젝트 지식 = ops `control/` + `status/` 연동. 세대 교체: 세션이 길어지면 같은 프로젝트 안에서 새 대화 시작 — 승계는 이 핸드오프(정본) + 전임 세션 검색(보조) 이중.
- 컨트롤룸 결정도 여전히 ① 전역 환경설정 ② 각 프로젝트 인스트럭션 ③ .md(ops 커밋)로 외부화해야 유효(타 프로젝트는 컨트롤룸을 검색 못함).
- 구 컨트롤룸(프로젝트 밖 세대, ~2026-07-17)은 이동 없이 은퇴 — 메모리 풀 기여 유지.
