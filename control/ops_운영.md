# ops 운영 (설계 + 파일 배치)

> 2026-07-21 통합: ops_레포_설계.md + ops_파일배치_가이드.md → 이 문서. 원본은 _archive/.

> **역할:** 전 프로젝트 save-state의 단일 정본 + 프로젝트 간 공유 상태 버스.
> 쓰기 = 사람/Claude Code. 읽기 = claude.ai GitHub 통합(프로젝트 지식에 **폴더 선택 연동**).
> **비공개 전용**이므로 전략·이직 정보 포함 무방. status/만 범공유 표면(민감 상세 제외).

## 1. 폴더 구조
```
ops/
├─ status/                  ← ★공유 표면: 프로젝트별 현황 요약 (전 프로젝트가 봐도 되는 수준)
│   ├─ swe.md  ai.md  algo.md  career.md(요약판)  lang.md   ← health.md 없음(건강은 건강 방에만)
├─ control/                 ← 컨트롤룸 전용: 핸드오프 v3, 전역 전략
├─ career/                  ← 커리어 전용: 이직 전략 상세, 회사별 분석 (민감 최상)
├─ swe/                     ← SWE 운영: 마스터플랜 본부판, 브리프, 복습트랙
├─ ai/                      ← AI 운영: 온보딩 패키지, 커리큘럼 요청서
├─ logs/                    ← Claude Code 세션 로그 (자동 커밋 대상)
└─ kit/                     ← claude-work 킷 백업 (CLAUDE.md·에이전트)
```

## 2. 연동 매트릭스 (claude.ai 프로젝트 지식 ← ops 폴더) — 2026-07-17 확대 개정
| claude.ai 프로젝트 | 연동 폴더 | 근거 |
|---|---|---|
| SWE | `status/` + `swe/` | 타 프로젝트 현황 인지 + 자기 운영 문서 |
| AI | `status/` + `ai/` | 〃 |
| 알고리즘 | `status/` | 운영 문서가 가벼워 현황만으로 충분 |
| **커리어** | `status/` + `career/` + `control/` | 전체 관제 — 유일하게 전략 상세까지 |
| **어학** | `status/` (2026-07-17 추가) | 커리어 어학 방침과 직결 — 토스/OPIc 충돌 사례로 필요성 실증 |
| 건강·운동 | 미연동 (원하면 status/ 선택) | 타 프로젝트 연관 낮음. 건강 정보는 건강 방에만 원칙 |
| 바이크 / 기타방 | 미연동 | 취미·catch-all은 전역 상태 불필요 |
| **컨트롤룸(프로젝트 승격, 2026-07-17)** | `control/` + `status/` | 역할 = **구조 변경**(매트릭스 개정·프로젝트 신설·판본 정책 등 메타 결정). 프로젝트화로 전임 세션 검색 + ops 상시 연동 확보 |

- **원칙: `status/`만 범공유, 민감 상세는 소관 프로젝트에만.** career/·control/은 커리어 전용 불변.
- status/는 범공유 표면이므로 **health.md는 두지 않는다**(건강 정보는 건강 방에만). career.md는 요약판 유지(방침·단계 수준).

## 3. status/{프로젝트}.md 표준 양식
```
# {프로젝트} 현황
- 갱신: YYYY-MM-DD (갱신 주체: 마스터방 산출 → 사람 커밋 / Code 세션)
- 단계: (한 줄)
- 최근 완료: (불릿 2~4)
- 진행 중 / 다음: (불릿 2~4)
- 타 프로젝트 전달사항: (있을 때만 — 이 줄이 프로젝트 간 통신 채널)
```
- 갱신 시점: 마스터방에서 의미 있는 결정·완료가 있을 때. 주기 강제 없음(형식적 갱신 금지).
- **"타 프로젝트 전달사항"이 방 간 메시지 버스**: 예) swe.md에 "AI 소관 후보 발견: RAG 청킹 전략 → ai로 이관 제안".

## 4. 운영 규칙
- Sync는 수동: 마스터방에서 논의 시작 전 "Sync now" 습관.
- 도메인 방(SWE 6방 등)은 **삭제하지 않음** — Q&A·신규 발굴 공간으로 유지하되, 관제 기능이 ops로 이동하므로 자연스럽게 가벼워짐. 방 유지 비용은 0.
- Claude GitHub App 권한은 ops 단일 레포만.
- 컨트롤룸 outputs의 기존 운영 문서들을 위 구조로 초기 커밋(초기 이관 맵은 아래 §5).
