# [커리어 방 전달] 개시 결정권 부여 + 도메인 학습 소관 확정 (2026-07-17)

발신: 컨트롤룸 / 수신: 커리어(방산) 프로젝트 방

## 1. 배경 요지
방산 이직 대비 기술 학습(임베디드·무선통신 등)의 운영 방안이 확정되었다. 콘텐츠는 3층으로 분리되며, 커리어 방은 이 중 **한 층의 소관 주체**이자 **나머지 층들의 개시 결정권자**가 된다.

| 층 | 내용 | 소관 |
|---|---|---|
| 방산 특화 | 소나·전자전·무기체계·MIL 규격·산업 구조 | **커리어 방 (이 방)** + ops/career |
| 통신 신호처리 일반 | 변조·채널·검출·RF/DSP | AI 프로젝트 (4단계 확장 트랙) |
| 임베디드 일반 | RTOS·인터럽트·펌웨어 | SWE X 카테고리 (예약 → 개시 대기) |

## 2. 부여되는 역할 ① — 개시 결정권
- SWE의 **X(임베디드) 개시**와 AI의 **통신 트랙 확정**은 모두 "**이직 준비기 진입**" 판단을 트리거로 한다. 이 판단은 **커리어 방의 단독 권한**이다(학습 방들은 자체 개시 불가).
- 판단 기준(제안 — 이 방에서 확정·조정할 것):
  - 점프 목표 시점(2028~29) 역산으로 **서류·기술면접 대비 학습이 필요해지는 시점**(대략 목표 1~1.5년 전)
  - 또는 채용 공고·JD 동향상 조기 대비가 유리하다고 판단되는 시점
- 신호 방법: ops `status/career.md`의 "타 프로젝트 전달사항"에 기재(예: "이직 준비기 진입 — SWE X 개시, AI 통신 트랙 확정 요청"). ops 구축 전에는 수동 전달.

## 3. 부여되는 역할 ② — 방산 도메인 학습의 홈
- 방산 특화 학습(소나·전자전·무기체계 등)은 이 방 산하 **[공통] 도메인 학습** 채팅에서 수행한다(기존 권고의 공식화). 학습량이 커지면 별도 프로젝트 승격 후보.
- **공개 절대 금지 원칙**: 이 층의 내용은 어떤 공개 레포(swe-notes·ai-engineering-notes·swe-projects)에도, 어떤 형태로도 게시하지 않는다. 기록은 이 방 + ops/career에만.

## 4. 커리어 방이 얻는 도구 (참고)
- ops 연동 완료 시 이 방은 `status/` + `career/` + `control/`을 읽는 **유일한 전체 관제자**가 된다 — 전 프로젝트 진행 상황(학습노트 게시 수, AI 로드맵 단계, 미니PJ 커버리지)을 자소서·면접 전략의 실증 자료로 직접 활용 가능.
