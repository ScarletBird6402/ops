# [AI 커리큘럼 브리프] 2026-09-14 — 실무 트랙 개시

> **반입 세트 3종**: 이 브리프 + `AI실무_커리큘럼_마스터플랜_v1.md`(v1.3 · 12카테고리 · 61항목 = 시드 40 + 교육 발원 채택 12 + 본부 보강 9) + `사내온보딩_패치_AI트랙보강_20260914.md`(확정판 규칙 6 보강 — 온보딩 문서 끝에 추가).

## 1. 개시 통보
- AI 프로젝트에 **실무 트랙(LLM·에이전트)** 이 개설되었다(컨트롤룸 확정 2026-09-02). 사내 에이전트 업무 발원분을 받는 창구.
- 국면 = **Phase 1(발굴·배정)**. 마스터플랜은 시드 40항목 + **사내 교육 발원 16주제(채택 12·흡수 4)** 로 출발한다. 시드는 "이런 것이 오면 여기"의 좌표이며, 접촉이 생겨야 착수한다. 교육 발원분·본부 보강분은 리스트 배정만 완료(생성 미착수).
- 교육 발원 배정 요지: 기존 골격에 없던 **프레임워크·실행 그래프 층**(호출 추상화·체인 조합·그래프 구현·서브그래프·체크포인터·동적 팬아웃)이 드러나 **AI-L 신설**(동결 전·말미 append). RAG 청킹/k값·하이브리드 검색(RRF)·MCP·장단기 메모리는 기존 시드의 사례로 **흡수**(키워드 보강). 본부 보강 9건은 AI-L의 내부 흐름(상태 스키마·메시지·도구 바인딩·스트리밍·실패 경로)과 질의 변환·회수/주입 단위·운영 중 평가·에이전트 행위 위험.
- **동결 전 최종 정렬(v1.3):** 코드 순서 = 학습 순서, 유사 토픽 인접 원칙으로 B·C·D·F·G·L 재번호. 반입본은 이 v1.3이 기준 — 이전 초안의 코드는 무효.
- 생성은 접촉 누적 후 시작한다(트리아지 먼저). **발굴이 우선** — 지금 단계에서 사내에 바라는 것은 `AI소관:` 줄을 빠뜨리지 않는 것 하나다.

## 2. 마스터플랜 반입
**신규 반입**(교체 아님). SWE 마스터플랜과 **나란히** 참조한다 — 코드 매핑 시 접두 유무로 정본을 고른다.
- 골격: AI-A 프롬프트 / AI-B 컨텍스트·메모리 / AI-C 출력 제어 / AI-D RAG / AI-E 도구 사용 / AI-F 에이전트 루프 / AI-G 멀티에이전트 / AI-H 평가 / AI-I 안전 / AI-J 모델 선택·비용·운영 / AI-K 모델 적응 / **AI-L 프레임워크·실행 그래프(v1.1 신설)**.
- 각 카테고리 하단에 **SWE 대칭항**을 적어 두었다. 경계 사례는 그 쌍으로 가른다.

## 3. 규칙 확정
1. **경계 기준(재확인):** "에이전트/LLM을 빼도 성립하는 원리인가?" 성립=SWE, LLM 특성 본체=AI. 한 상황이 두 보고로 갈라지는 것이 정상 — 패치 6-3 표 참조.
2. **코드 표기:** `AI-` 접두 필수(`AI-E2`). 접두 없으면 SWE. 사내 자체 넘버링은 제목 병기.
3. **`AI소관:` 3요소:** 주제 / 키워드 3~5 / 제안 카테고리 / 인접 `AI-` 코드 1개(없으면 `인접: 없음`). 기존 코드 접촉은 `AI접촉:` 줄에 코드+횟수만.
4. **채택 vs 흡수:** SWE 규칙 준용 — 기존 항목의 적용 사례면 흡수, 신규 원리가 본체면 채택. 흡수처는 원리를 정의한 항목 우선.
5. **동결 정책(예고):** v1.3에서 동결 전 정렬을 마쳤다. 자료 0건인 동안은 아직 재배열 가능하나 추가 재배열은 예정 없음. **첫 자료 게시 시점에 동결** — 이후 코드 회수·시프트 금지, 카테고리 신설은 `AI-L`부터 말미 append만. SWE의 동결 전 재배열 경험을 그대로 적용해, 초기 배정 몇 건으로 골격의 빈 곳이 드러나면 동결 전에 손본다.
6. **최신성 표기:** 이 트랙 자료의 모델·도구·API 명칭에는 "(202X-MM 기준)" 시점 표기가 붙는다. 반감기가 짧은 분야라는 뜻이며, 보고 시 제품명은 그대로 적어도 된다(본부가 개념화·시점 처리).
7. **작업 방식 중립화(준용):** 특수 도구·협업 구조에서 발원한 보고도 일반 워크플로우 관점으로 정의된다. 보고 시 미리 일반화할 필요 없음.

## 4. 사내에서 할 일 (이번 주부터)
