# AI 역량 구축 방 — 커리큘럼 요청서 (방산 전략 방 발신)

> **이 문서의 성격:** 방산 이직 전략 방에서 정의한 "방산 음향 AI 직무 요건"을 근거로, AI 역량 구축 방이 수행할 학습·재현 커리큘럼을 역산해 정리한 인계 문서.
> **수신 방(AI 방)에 대한 요청:** 이 문서를 시작점으로, 아래 커리큘럼을 실행 계획으로 구체화하고 진행 상황을 누적 관리해 주세요. 진행하며 정리된 스킬/지식은 방산 방이 자소서·PT 근거로 회수합니다.
> **절대 기준:** 범용 AI를 넓게 공부하는 문서가 아님. 방산 전략 방의 **단일 주축(소나·패시브 음향 방위추정)**과 **키스톤 산출물(DCASE SELD)**에 정렬된 것만 다룸. 정렬되지 않은 주제는 이 커리큘럼에서 제외.

## 0. 배경 (AI 방이 알아야 할 전제)

- **최종 목표:** 방산 3사(선호 KAI > 한화 > LIG / 적합도 LIG ≈ 한화 > KAI) 센서 AI 직무로 이직. 점프 시점 2028~2029.
- **핵심 서사(방산 방에서 확정):** "고전 신호처리 + 딥러닝을 모두 다루며, 미션크리티컬 시스템을 책임져본 음향·센서 AI 엔지니어."
- **AI 방의 임무:** 위 서사의 **가장 큰 하중 부재 = "현재형 AI 역량 증거"**를 만든다. 마지막 hands-on AI가 ~2021년이라 신선도 갭이 있음. 이 갭을 *최근 날짜의 음향 AI 산출물 1개*로 덮는 것이 AI 방의 존재 이유.
- **키스톤 산출물:** DCASE SELD(Sound Event Localization and Detection) 트랙 베이스라인 재현·개선 → GitHub 공개. 본격 챌린지는 약 9개월 뒤 개막. 금년은 준비기.
- **성공 정의:** 챌린지 우승이 아님. **"과거에 했다"를 "지금도 한다"로 바꾸는, 공개 가능한 증거물 1개.** 완결성 > 순위.

## 1. 직무 요건 → 필요 역량 매핑 (역산의 근거)

방산 음향 AI 직무가 요구하는 것과, 그것을 증명할 학습 항목의 대응표. **이 표가 커리큘럼의 정당성 근거다.**

| 방산 직무 요건 | 대응 역량 | 현재 상태 | 커리큘럼에서 다룰 것 |
|---|---|---|---|
| 패시브 음향 방위추정 / DOA | 어레이 신호처리, ITD/ILD, cross-correlation 기반 방위추정 | 석사연구·HRTF 논문으로 **개념 보유**, 코드 재현은 공백 | SELD의 DOA 추정 파트 재현 |
| 실시간·온디바이스 표적 음향인식 | SED/SER, 스트리밍 추론, 경량화 | SER 논문 개념 보유(75% overlap), 최신 구현 공백 | SED 베이스라인 재현 + 실시간화 |
| 센서 데이터 → 의미 추출 파이프라인 | 특징추출(Mel/MFCC), CNN/CRNN/Conformer | 고전 특징 보유, 최신 아키텍처(Conformer 등) 공백 | 최신 SED 아키텍처 학습 |
| 미션크리티컬 프로덕션 AI | 재현성, 실험관리, 배포 관점 | 운영 경험 보유, AI 프로덕션 접점 공백 | Test Case AI 사내과제 + 재현성 습관화 |
| (확장) RF·제어로의 전이 | 어레이 신호처리·파동 공통성 | 음향으로 증명 후 확장 — **이 커리큘럼 범위 밖**, 음향 완결 후 검토 | (제외 — 주축 침범 금지) |

> **주의:** 마지막 행(RF·제어)은 방산 방의 "확장 각도"이지 AI 방의 학습 대상이 아님. 음향 주축이 완결되기 전에 손대지 말 것. 분산 방지.

## 2. 커리큘럼 (3단계, 본업 병행 전제)

전제: **본업(삼성 DS) 병행. 주당 가용 시간은 제한적.** 따라서 "완주 가능한 최소 단위"로 설계. 각 단계는 이전 단계 산출물 위에 쌓임.

### 단계 1 — AI 기초 재가동 (준비기 전반)
> 목표: 2021년에 멈춘 감각을 되살리고, 현재 도구 체인(PyTorch 최신, 실험환경)에 다시 적응.

- Python/PyTorch 현행화: 예전 코드 습관과 현재 API 차이 메우기
- 딥러닝 기초 복습을 *음향 태스크로* 진행 (범용 이미지 예제 말고 오디오로 — 주축 정렬)
- 오디오 특징추출 파이프라인 손으로 다시 짜보기: waveform → Mel-spectrogram/MFCC (석사 때 개념은 있으니 *구현 감각* 복원이 목표)
- 작은 SED 태스크 1개 end-to-end 완주 (데이터 로드 → 학습 → 평가). 규모보다 *완주*가 목적
- **산출물:** 재현 가능한 미니 SED 학습 코드 1개 (README 포함, 로컬/GitHub)

### 단계 2 — SELD 베이스라인 재현 (준비기 후반)
> 목표: DCASE SELD 공식 베이스라인을 *돌려보고 이해*한다. 이게 키스톤의 심장.

- DCASE SELD 태스크 구조 파악: SED(무슨 소리) + DOA(어느 방향) 결합 구조 이해 — **방산 방위추정과 직결되는 지점**
- 공식 베이스라인 코드 클론 → 환경 세팅 → 재현 실행
- 평가 지표 이해: SED 지표 + DOA 오차 지표(방산 PT에서 "방위추정 정확도"를 말할 때 쓸 언어)
- 베이스라인 결과를 내 손으로 재현 (숫자 일치 확인)
- **산출물:** SELD 베이스라인 재현 리포트 (환경·과정·결과 정리, 재현성 강조) — *"지금도 한다"의 1차 증거*

### 단계 3 — 개선 시도 + 공개 (챌린지 개막 전후)
> 목표: 베이스라인에 *내 손길* 하나 얹어 "재현자"에서 "개선자"로. 그리고 공개.

- 베이스라인의 한 지점을 골라 개선 실험 (예: 특징·증강·아키텍처 한 요소). 큰 혁신 불필요, *내가 설계한 변경 1개*면 충분
- 결과 비교·분석: 왜 나아졌나/안 나아졌나를 신호처리 언어로 설명 (면접에서 그대로 쓸 서사)
- (여력 되면) DCASE 챌린지 실제 제출
- **산출물:** GitHub 공개 레포 (베이스라인 재현 + 개선 실험 + 분석 README). **`방산전략_v2` 9절의 ★키스톤 = 이것.**

## 3. 방산 방으로 회수할 것 (역방향 신호)

AI 방이 진행하며 아래가 정리되면 방산 방으로 넘겨주세요. 방산 방이 자소서·PT 근거로 씁니다.

- [ ] 재현·개선한 SELD 산출물의 **한 줄 요약 + GitHub 링크** → `방산전략_v2` 4절 "★현재형 AI 역량" 증거 확정
- [ ] DOA 추정에서 실제로 다룬 **구체적 방법·지표 용어** → LIG 기술 PT 스크립트 재료
- [ ] 개선 실험의 **"왜"에 대한 설명** → 면접 STAR "최근 기술 문제 해결" 소재
- [ ] 학습 중 재확인한 **최신 스킬 목록**(아키텍처·도구) → 자소서 "IT활용능력"·직무역량 항목 현행화

## 5. AI 방 운영 요청 (규칙 제안)

> **[2026-07-01 컨트롤룸 결정 반영 — A안 확정]**
> AI 방은 이직과 무관하게 누적되는 **영구 학습 자산**이며, 방산 이직 종료 후에도 존속한다(**병합 없음**). 따라서 아래 "음향만·범용 제외" 규칙은 **AI 방 전체 규칙이 아니라, 방산 키스톤(DCASE SELD)을 다루는 "집중 스레드"에만 적용된다.** AI 방은 그 밖의 학습 주제를 자유롭게 다룰 수 있다.

**(가) 키스톤 스레드 한정 규칙** — DCASE SELD 재현·개선·공개를 다루는 스레드에서만 적용:

- 이 스레드의 학습은 **음향(SED/SELD/DOA) 태스크로** 진행. 범용 예제(이미지 분류 등)로 새지 말 것 — 주축 정렬. *(키스톤 스레드 한정)*
- **완주 > 규모.** 본업 병행 전제이므로, 크게 벌이고 못 끝내는 것보다 작게 끝내는 걸 우선.
- 각 산출물은 **재현 가능·공개 가능** 형태로 (README·환경 명시). 미션크리티컬 서사와 맞물리는 "재현성" 습관 자체가 자산.
- 신선도 갭을 덮는 게 목적이므로, **산출물에 최근 날짜가 남게** 할 것.

**(나) AI 방 전체 공통** — 스레드 무관 적용:

- 진행 상황을 누적 관리하고, 3절 항목이 정리될 때마다 방산 방으로 회수 신호(양방향 다리, §3).
- 키스톤 외 학습 주제는 AI 방 자율. 방산 방은 관여하지 않음(범용 맥락 분리 원칙과 일치).
