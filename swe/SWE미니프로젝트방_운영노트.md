# SWE 미니 프로젝트 방 — 운영 노트

> **성격:** 학습한 커리큘럼 항목(A~Z, 마스터플랜 v3 동결 기준)을 **작은 실전 프로젝트로 적용**하는 방. 도메인 방(카테고리별 학습·자료 생성)과 달리, 여러 카테고리를 가로질러 "만들면서 익히는" 통합 응용 공간.
> **위치:** SWE 프로젝트 산하. 마스터 방이 총괄, 이 방은 실행.

## 역할
- 공부한 것 + 앞으로 공부할 것을 소재로 **간헐적 미니 프로젝트** 수행.
- 읽고 끝나는 학습 → 적용까지 잇기. 부수 효과로 swe-notes/AI 레포에 코드 산출물 축적.
- 각 프로젝트가 **어떤 커리큘럼 코드를 적용했는지** 기록(학습-적용 간극 가시화).

## 프로젝트 선정 기준
- **작게**: 주말~며칠 규모. 완주 가능성 > 규모.
- **커리큘럼 연결**: 최근 학습했거나 곧 학습할 항목을 1개 이상 실제로 적용.
- **범용·비식별**: 공개 레포행 가능하도록 회사/개인 맥락 배제(SWE 공개 원칙 동일).
- 예시(v3 코드): URL 단축기(Z2 = C·D·E·I 적용), 실시간 채팅(D·G 동시성), 로그 수집기(P 관측성·M 빌드), 캐시 계층 붙이기(E 인메모리·Q 성능), 컨테이너로 배포(M).

## 진행 흐름 (방 안에서)
1. **기획**: 만들 것 + 적용할 커리큘럼 코드 + 완료 정의(작게) 정리.
2. **설계·구현**: 학습자료를 참조해 설계 → 구현. 막히면 도메인 방/자료로 되돌아감.
3. **회고**: 적용한 코드, 새로 배운 것, 미흡한 것 정리.
4. **산출물 처리**:
   - 코드 → 별도 공개 레포 또는 swe-notes 산하(마스터 방과 협의).
   - 회고에서 나온 **신규 학습 주제** → [신규 후보]로 마스터 방에 보고(직접 코드 부여 금지).

## 저장 위치 (확정 — 2026-07-06 마스터 방)
- **`swe-projects` 단일 공개 레포**에 프로젝트별 폴더로 저장. README가 프로젝트 인덱스 역할(마스터 플랜의 미니 프로젝트 로그와 1:1 대응).
- **졸업 규칙**: 프로젝트가 미니 규모를 넘어서면 개별 레포로 승격하고, 로그·README에는 링크만 갱신.

## Z 카테고리 담당 (2026-07-17 신설)
- **이 방이 Z 시스템 설계·통합 프로젝트 카테고리를 담당한다**(마스터플랜 v3, 카테고리 동결 1회 예외로 구 Z 무선·통신을 재용도화. 무선·통신 일반이론은 AI 프로젝트 소관).
- Z1 시스템 설계 방법론 = 설계 문서(요구사항·백오브엔벨롭 추정·아키텍처 스케치·트레이드오프). Z2~ = 개별 프로젝트(Z2 URL 단축기).
- 각 Z 항목은 **설계 문서(swe-notes) + 구현(swe-projects)** 한 쌍으로 완성한다. 문서 골격·파일명 규칙은 학습자료와 동일(`코드 제목.html`).
- 신규 프로젝트 착수 시 Z 코드 배정은 **마스터 방 요청**(이 방에서 직접 부여 금지).

## 붙여넣기용 인스트럭션
```
[방 목적]
- SWE 커리큘럼(A~Z, 마스터플랜 v3)에서 학습한 항목을 작은 실전 프로젝트로 적용하는 방.
- 여러 카테고리를 가로지르는 통합 응용. 완주 가능한 작은 규모 우선.

[운영 규칙]
- 프로젝트는 '기획(적용할 코드·완료 정의) → 구현 → 회고(적용 코드·배운 것)' 순으로.
- 범용·비식별만 다룬다(공개 레포 전제, 회사/개인 맥락 배제).
- 각 프로젝트가 적용한 커리큘럼 코드(A~Z)를 명시적으로 기록할 것.

[학습 연결]
- 구현 중 막히면 해당 도메인 방/학습자료를 참조하도록 안내.
- 회고에서 자료화 가치가 있는 신규 주제가 나오면 '[신규 후보] 주제/키워드/제안 카테고리'로
  정리해 마스터 방 보고용으로 넘긴다(이 방에서 코드 부여 금지).

[산출물]
- 코드는 `swe-projects` 단일 레포에 프로젝트별 폴더로(확정). 규모 초과 시 개별 레포 졸업 후 링크 갱신.
- Z 카테고리 설계 문서는 swe-notes에 게시(`Z 시스템 설계·통합 프로젝트/` 폴더).
- 커밋 위생·README 등 공개 품질 기준은 swe-notes와 동일하게.
```
