# [마스터 방 전달] 미니 프로젝트 방 신설

## 1. 개요
SWE 프로젝트 산하에 **미니 프로젝트 방**을 신설한다. 학습한 커리큘럼 항목(A~Z, 마스터플랜 v3 동결 기준)을 작은 실전 프로젝트로 적용하는 통합 응용 공간. 도메인 방(카테고리별 학습)과 역할이 구분됨.

## 2. 마스터 방이 관리할 항목 (총괄 역할 확장)
1. **저장 위치 확정**: 미니 프로젝트 산출물을 (A) 프로젝트별 개별 공개 레포 / (B) `swe-projects` 단일 레포 중 어디에 둘지 결정. 첫 프로젝트 착수 전 확정.
2. **커버리지 추적**: 각 미니 프로젝트가 적용한 커리큘럼 코드를 마스터 플랜 옆에 기록 → "학습(계획) vs 적용(실전)" 간극 파악. 아직 실전 적용이 없는 카테고리를 다음 프로젝트 소재로 유도.
3. **신규 후보 수신**: 미니 프로젝트 회고에서 올라온 [신규 후보]를 기존 트리아지 기준으로 처리(재확인이면 제외, 새 각도면 채택·코드 배정).
4. **프로젝트 로그**: 진행/완료된 미니 프로젝트 목록을 마스터 방 save-state에 인덱싱(제목·적용 코드·상태·레포 링크).

## 3. 커버리지 로그 양식 (마스터 플랜에 부기)
```
[미니 프로젝트 로그]
| 프로젝트 | 적용 코드 | 상태 | 레포 |
|---|---|---|---|
| (예: Z2 URL 단축기) | C10·D2·E1·I1·P1·S3 | 진행 | (링크) |
```

## 4. 방 개설 시
- 첨부: `실무역량_운영문서.md` 부록 A(운영 노트 + 인스트럭션).
- 제목 규칙: `[미니PJ] 프로젝트명`.
- 첫 작업: ~~저장 위치 확정~~(완료 — `swe-projects` 단일 레포) → 첫 프로젝트 = **Z2 URL 단축기** 진행 중.
- **Z 카테고리 담당**(2026-07-17): 이 방이 Z 시스템 설계·통합 프로젝트를 담당. Z1 설계 방법론 + Z2~ 개별 프로젝트. 코드 배정은 마스터 방.
