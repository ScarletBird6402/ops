## 4. 기타 운영 변경 (통합)

1. **자료 생성 일원화** — 학습자료 HTML 생성은 본부 전용. 사내는 반입본에 `## 실무 연결` 섹션을 **"관련 문서" 직전에 추가만** 한다(본문·링크·기존 예시 무수정). 편집 시 파일 전체가 아니라 삽입 지점 주변만 컨텍스트에 넣을 것. 파생본·실무 사례는 사외 반출 금지.
   ```html
   <h2>실무 연결</h2>
   <blockquote class="info"><p>원본 기준: YYYY-MM-DD · 이 섹션은 사내 파생본 전용.</p></blockquote>
   <ul>
     <li>(업무에서 경험한 사례·연관 지점을 여기에)</li>
   </ul>
   ```
2. **보고 범위** — 기존 코드 접촉분도 매 보고에 포함(형식: `접촉: K5, I8, M1`). 재접촉 가중 정렬의 유일한 입력. **배정 ≠ 생성 착수** — 배정만 되고 생성 대기인 항목도 전부 플랜에 등재됨(누락 아님).
3. **생성 캐던스** — 병목은 과도기 스톡 문제. 즉시 학습은 Q&A로, 당장 필요한 주제는 엔트리에 `[긴급]` 태그(익일 반입 목표, 상한 주 2~3건). 스톡 소진 후에는 생성 여력이 남아 베이스 카테고리로 전환.
4. **보고 형식** — 코드+제목 병기 필수. 07-13 이후 보고에서 병기 형식이 정착되어 해석 모호성 0건 — 유지 바람.
