# 사내 Claude 온보딩 — AI 트랙 보강 패치 (2026-09-14)

> 확정판(2026-09-02, 주간 전송 블록 + AI 분기)의 **규칙 6을 보강**한다. 확정판의 나머지는 그대로. 근거: AI 실무 커리큘럼 마스터플랜 v1 반입으로 `AI-` 코드 체계가 생겼으므로, `AI소관:` 항목도 SWE 신규와 같은 수준의 정보로 본부에 넘길 수 있게 됨.

---

## 규칙 6 보강 — `AI소관:` 항목의 형식

### 6-1. 3요소 한 줄 (SWE `신규:`와 동일 원칙)
```
AI소관:
 · 주제 / 키워드 3~5 / 제안 카테고리(AI-A~L) / 인접 AI- 코드 1개
```
- 제안 카테고리는 마스터플랜 v1.3의 12개 중 하나. 모르면 `카테고리: 미정`.
- 인접 코드는 마스터플랜 v1에서 가장 가까운 항목 하나. 없으면 `인접: 없음`. 분업 논거·경위는 쓰지 않는다 — 인접 코드로 본부가 판정한다.

### 6-2. `AI접촉:` 줄 (선택, 기존 AI- 코드가 있을 때만)
```
AI접촉: AI-D2 AI-E1×2 AI-I2
```
- SWE `접촉:`과 같은 규칙 — 코드+횟수만, 설명 없음. 마스터플랜에 있는 코드만.
- `AI접촉:`은 `AI소관:` 바로 위에 둔다. 둘 다 없으면 두 줄 모두 생략.

### 6-3. 판정 기준은 하나, 적용은 "쌍"으로
판정 기준: **"에이전트/LLM을 빼도 성립하는 원리인가?"** — 성립하면 SWE, LLM 특성이 본체면 AI.
같은 업무 상황이 **두 보고로 갈라지는 것이 정상**이다. 아래 표의 쌍을 기준으로 가른다. 한 상황에서 두 쪽이 다 나오면 각각 `신규:`/`접촉:`과 `AI소관:`/`AI접촉:`에 나눠 적는다.

| 업무 상황 | SWE 쪽 (`신규:`/`접촉:`) | AI 쪽 (`AI소관:`/`AI접촉:`) |
|---|---|---|
| 도구 호출 인자가 틀림 | 인자 **스키마 검증**·입력 경계 (D13·I16·S10) | 모델이 인자를 **환각**·오선택 (AI-E2) / 도구 **설명** 설계 (AI-E1) |
| 모델 출력 JSON이 깨짐 | 파서 견고성·부분 실패 처리 (I20·D12) | 형식을 **지키게 하는** 프롬프트·제약 디코딩 (AI-C1) / 절단 (AI-C4) |
| 에이전트가 무한 루프 | 타임아웃·재시도 상한·상태 머신 (G·H5) | 종료 조건·자율성 수준 설계 (AI-F3) / 재계획 실패 (AI-F2) |
| 검색 결과가 답에 안 반영됨 | 검색 서비스 장애·인덱스 갱신 (E·F) | 청킹·재순위·주입 순서 (AI-D2·AI-D5·AI-D6) |
| 외부 문서 속 지시를 모델이 따름 | 입력 신뢰 경계 일반 (S3·S10) | **자연어 지시가 공격 벡터** — 간접 인젝션 (AI-I2) |
| 응답이 느림·비용 급증 | 캐시·큐·백프레셔 (Q3·G4) | 토큰 예산·프롬프트 캐시·모델 라우팅 (AI-B1·AI-J2·AI-J1) |
| 같은 입력에 매번 다른 결과 | 테스트 결정성 일반 (J11) | 비결정 출력의 평가 전략 (AI-H2) |
| 모델 버전 바뀌자 동작 변화 | 의존성 버전 고정 (M1) | 품질 드리프트·회귀 평가 (AI-J4·AI-H1) |
| 시스템 프롬프트 내용이 노출 | 비밀 관리 (S5) | 프롬프트 경유 유출·최소 주입 (AI-I4) |
| 여러 에이전트 인계 중 조건 누락 | 메시지 계약·직렬화 (D·C10) | 인계 시 컨텍스트 손실 (AI-G3) |
| 그래프 프레임워크(예: LangGraph) 구성·영속성·병렬 | 상태 머신·워크플로 엔진·저장소 교체·병렬 실행 일반 (G·I·E12·G4) | 모델 출력이 제어 흐름·작업 수·재개 지점을 결정하는 계약 (AI-L4·AI-L7·AI-L9) |
| 사람 승인 후 실행 재개 | 승인 워크플로·감사 로그 일반 (K·P1) | 도구 실행 전 중단·체크포인트 재개 (AI-F4) |

### 6-4. 애매하면
`판단요청:`에 한 줄. **양쪽 후보 코드를 병기**한다(예: `판단요청: 도구 결과 요약 규칙 — I27 vs AI-E3`). 본부가 판정 후 이관 회신.

### 6-5. 표기 규칙 재확인
- AI 코드는 항상 `AI-` 포함(`AI-E2`). 접두 없는 코드는 전부 SWE.
- 사내 자체 AI 넘버링이 있으면 **제목 병기**(SWE와 동일 처리).
- 블록 15줄 상한은 `AI소관:`·`AI접촉:` 포함 기준. 넘치면 신사례 → AI소관 키워드 축약 순으로 줄인다.

## 예시 (에이전트 업무 발원 주간 블록)
```
[W38 주간 · 09/14~09/20]
접촉: K5×2 I16 D12
신사례(선택): —
신규:
 · 도구 결과 캐시 무효화 시점 / 캐시·TTL·도구 결과·재호출 / Q / Q3
AI접촉: AI-E1
AI소관:
 · 유사 도구 3개 중 오선택 반복 / 도구 설명·이름 충돌·선택 정확도 / AI-E / AI-E1
 · 검색 문서 안의 지시를 모델이 따름 / 간접 인젝션·신뢰 경계·격리 / AI-I / AI-I2
판단요청: 도구 결과 요약 규칙 — I27 vs AI-E3
```

## 반입 주의 (AI 자료, 향후)
- `AI-` 학습자료 HTML은 본부 공개 저장소의 **하위 폴더 구조(`AI-X 카테고리명/`)** 안에 두어야 문서 간 상대 링크가 열린다. SWE 자료와 같은 원칙 — 개별 파일만 옮기면 링크가 깨진다.
- AI 자료 본문의 모델·도구 명칭에는 **시점 표기**가 있다. 반입 후 시간이 지난 자료는 그 시점 기준으로 읽는다.
