# [기타] 방 — 운영 노트

> **성격:** 홈이 없는 잡다한 주제·일회성 질문·탐색적 대화의 기본 수용처(catch-all).
> 컨트롤룸(전략)과 각 프로젝트를 깨끗하게 유지하기 위한 **완충 + 인큐베이터** 공간.
> (구 "메모리 업데이트 확인" 방을 이 용도로 전환)

## 역할
- 어느 프로젝트에도 속하지 않는 일회성 질문·잡문·빠른 작업.
- 아직 분류되지 않은 새 관심사가 잠시 머무는 임시 인큐베이터.

## 라우팅 (들어오면 먼저 판단)
- 기존 프로젝트에 명백히 속하면 → 그 프로젝트로 안내(여기서 처리하지 않음).
  예: 방산 자소서·면접 → 커리어 / 기술 학습·CS → SWE / 운동·통증 → 건강·운동 /
  영어 말하기 → 어학 / 전략·Claude 기능 → 컨트롤룸.
- 홈이 없으면 → 여기서 처리.

## 승격 조건 (핵심 — 프로젝트로 분리)
- 한 주제가 다음 중 **2개 이상** 충족하면 "승격 후보"로 표시하고 알릴 것:
  누적 참조(반복해서 되돌아봄) / 자료 축적(모아둘 산출물 발생) / 맥락 반복(유사 대화 재발).
- 판정은 시간 경과가 아니라 **"두 번째 사용 시 누적 유용성"**.
- 승격 시: 해당 주제 대화를 **save-state(.md)로 요약해 새 프로젝트로 이관**(인큐베이션 소실 방지).

## 유지 원칙
- 가볍게. save-state 불필요(일회성이 기본). 승격 후보만 별도 플래그.
- 이 방에 특정 주제가 계속 쌓이면 그 자체가 분리 신호.

## 붙여넣기용 인스트럭션
```
[방 목적]
- 홈이 없는 잡다한 주제·일회성 질문·탐색적 대화의 기본 수용처(catch-all).

[운영 규칙]
- 기존 프로젝트(커리어/SWE/AI/건강·운동/어학)나 컨트롤룸에 명백히 속하는 주제는
  해당 방으로 안내하고 여기서 처리하지 않는다. 홈이 없는 것만 여기서 처리.
- 가볍게 유지. save-state 불필요.

[승격 판단]
- 한 주제가 '누적 참조 / 자료 축적 / 맥락 반복' 중 2개 이상 충족하면
  "프로젝트 승격 후보"로 표시하고 먼저 알릴 것. 판정 기준은 시간이 아니라
  두 번째 사용 시 누적 유용성.
- 승격 시 해당 주제를 save-state(.md)로 요약해 새 프로젝트로 이관하도록 제안한다.
```
